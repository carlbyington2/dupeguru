Aide de dupeGuru
================

Ce document d'aide est également disponible dans les langues suivantes :

* `Anglais <../en/index.html>`__
* `Français <../fr/index.html>`__
* `Allemand <../de/index.html>`__
* `Arménien <../hy/index.html>`__
* `Russe <../ru/index.html>`__
* `Ukrainien <../uk/index.html>`__

dupeGuru est un outil permettant de trouver les fichiers en double sur votre ordinateur. Il
possède trois modes, Standard, Musique et Image, chaque mode ayant ses propres types d'analyse
et ses petites fonctionnalités.

Bien que dupeGuru puisse facilement être utilisé sans documentation, la lecture de ce fichier
vous aidera à le maîtriser. Si vous cherchez des conseils pour votre première analyse de
doublons, vous pouvez consulter la section :doc:`Démarrage rapide <quick_start>`.
